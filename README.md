**E-Commerce Sales & Customer Analytics**

1. Project Overview
   
This project is a SQL-based E-Commerce Sales and Customer Analytics project developed using MySQL .

The purpose of the project is to analyze sales performance, customer purchasing behavior, products, categories, regions, order trends, and returns using SQL queries.

The database is named ‘final_project_ecommerce’ and contains five related tables: Regions, Customers, Products, Orders, and OrderDetails . The tables are connected using primary keys and foreign keys to represent relationships between customers, regions, orders, and products.
The SQL script creates the database and tables, inserts the dataset, and performs different levels of sales and customer analysis.

2. Objective
   
The main objectives of this project are:
-   Analyze overall e-commerce sales and revenue.
-   Compare revenue across years and months.
-   Analyze product and category performance.
-   Calculate Average Order Value (AOV).
-   Understand customer purchasing behavior.
-   Identify high-value and repeat customers.
-   Segment customers based on total spending.
-   Calculate Customer Lifetime Value (CLV).
-   Analyze regional sales and order volume.
-   Study product return rates and customer returns.
-   Identify sales and return trends over time.

3. Technology Used

-   Database: MySQL
-   Tool: MySQL Workbench
-   Language: SQL
-   Project Type: Data Analysis / Business Analytics

4. Database Schema
   
The project uses the following five tables:

Table	             --->                     Purpose

`Regions`	      --->             Stores region and country information

`Customers`	     --->             Stores customer details and their region

`Products`	     --->             Stores product name, category, and price

`Orders`	       --->             Stores customer orders, order dates, and return status

`OrderDetails`  --->          Stores products and quantities associated with orders

5. Table Relationships

-  `Customers.RegionID` → `Regions.RegionID`
-  `Orders.CustomerID` → `Customers.CustomerID`
-  `OrderDetails.OrderID` → `Orders.OrderID`
-  `OrderDetails.ProductID` → `Products.ProductID`

The database structure and foreign-key relationships are defined directly in the SQL script.

6. Dataset

The SQL script contains sample e-commerce data for customers, products,
orders, order details, and regions.
The dataset includes:
-   10 regions
-   200 customers
-   Product records across different categories
-   Orders with order dates and return status
-   Order details containing product quantities
The customer records are connected to regions, while orders are connected to customers and order details are connected to both orders and products.

7. Analysis Performed

i. General Sales Insights

The project calculates:
-   Total revenue for the complete dataset.
-   Revenue excluding returned orders.
-   Revenue by year and month.
-   Revenue by product and category.
-   Overall Average Order Value (AOV).
-   Monthly AOV.
-   Average order size by region.

Revenue is calculated using the relationship between product price and
ordered quantity:
Revenue = Quantity × Product Price
The SQL script includes queries for total revenue, revenue excluding
returned orders, monthly revenue, product revenue, and AOV.

ii. Customer Insights

Customer behavior is analyzed using:
-   Top 10 customers by total revenue spent.
-   Repeat customer rate.
-   Average time between consecutive orders.
-   Customer segmentation based on total spending.
-   Customer Lifetime Value (CLV).
The project uses SQL subqueries, `CTEs`,`ROW_NUMBER()`, `DATEDIFF()`, and `CASE` statements for customer analysis. 
Customer segments used in the project are:

Segment              Total Spend

Platinum      -->     \> 1500

Gold          -->    1000--1500

Silver        -->     500--999

Bronze        -->    \< 500

CLV is calculated from the total revenue generated by each customer inthe available order data.

iii. Product & Order Insights

The project identifies:
-   Top 10 products by quantity sold.
-   Top 10 products by revenue.
-   Products with the highest return rate.
-   Sales performance of different product categories.
The return-rate analysis uses `CTEs` to compare total quantities sold withreturned quantities.

iv. Temporal Trends

The SQL analysis studies sales over time, including:
-   Monthly sales trends.
-   Revenue by year and month.
-   Monthly Average Order Value.
-   Recent 12-month sales trends based on the maximum order date in the dataset.
The script uses date functions such as `YEAR()`, `MONTH()`, and `DATE_FORMAT()` for temporal analysis.

v. Regional Insights

Regional performance is analyzed using:
-   Order volume by region.
-   Revenue by region.
-   Average order size by region.
-   Average product price by region.
-   Category sales trends.
The analysis connects `Orders`, `Customers`, and `Regions` to understand how sales and orders vary across regions.

vi. Return & Refund Insight

The project analyzes returns using:
-   Return rate by product category.
-   Return rate by region.
-   Customers with frequent returns.
-   Products with high return rates.

The `IsReturned` field in the `Orders` table is used to identify returned orders.

8. How to Run the Project

Step 1: Install MySQL
Install MySQL Server and MySQL Workbench.

Step 2: Open the SQL File
Open: `E_Commerce Sales and Analytics.sql` in MySQL Workbench.

Step 3: Execute the Script
Run the complete SQL script. It will:
1.  Create the `final_project_ecommerce` database.
2.  Create the five tables.
3.  Insert the sample data.
4.  Execute the analysis queries.

Step 4: Select the Database
If necessary, run:
`USE final_project_ecommerce`;

Step 5: Execute Individual Analysis Queries
The analysis queries are organized into sections such as General Sales
Insights, Customer Insights, Product & Order Insights, Temporal Trends,
Regional Insights, and Return & Refund Insights.
